### What the product does:
It is a AI chat in german that helps people on legal and financial aspects making use of RAG. Its responses should mainly focus on the files and documents that are stored in its own data base. 

### Who uses it:
The goal is to have it run in the internet and used by student of a univerity. Goal is that it can be run by at least 3 diferent users at the same time and a total of 2000 accounts should be able to have. 

### Tech constrains:
- The AI-chat has to run on Open Web UI with the verion v0.6.5 
- Each module should be run on Docker containers. Example: Frontend, Pipeline, Backend
- The models are used have to be open source
- It should be easy to maintain 
- For the prototype 

IMPORTANT: The used language for the chat is German
